# Code of conduct

Be respectful, specific and constructive. Harassment, threats, discriminatory abuse and
publication of private information are not accepted. Critique behavior and technical work,
not people. Maintainers may remove content or restrict participation for violations.

Report incidents privately through the repository owner's GitHub profile contact. Avoid
posting private reports in public issues. Maintainers will consider reports in context and
protect confidentiality as far as practical.
